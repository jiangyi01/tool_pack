# tool_pack

Small macOS utilities.

| Tool | What it does |
| --- | --- |
| [LittleBox](LittleBox/) | Menu bar helper for MacBooks with a notch: icons the notch hides appear in a strip under 📦, and resting on one opens its own menu. |

Each tool has its own README with build instructions. They build with the Xcode Command Line Tools (no full Xcode needed) and run on macOS 14 or later.
